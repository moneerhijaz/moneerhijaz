## Projects

### [ROS 2 Rover](https://github.com/moneerhijaz/autonav-rover-drone)

An in-progress tracked rover built around ROS 2 Jazzy, serial micro-ROS, and a Teensy 4.1. The firmware translates velocity commands into differential motor output and includes a command timeout. Odometry, autonomous navigation, and drone integration remain future work; the current focus is a dependable drive base.

### [Media Manager](https://github.com/moneerhijaz/media-manager)

A Linux CLI and web dashboard for inspecting and repairing media libraries. It combines subtitle synchronization, optional lip-sync analysis, and conservative crop checks with SQLite state and resumable checkpoints. Candidate changes are verified before replacement, while uncertain results remain visible for review.

### [JARVIS](https://github.com/moneerhijaz/jarvis)

An experimental local AI assistant with a Python backend, React interface, and persistent Markdown memory. Its pipeline connects an OpenAI-compatible model server to tools for files, commands, and retrieval. It is intended for local experimentation; optional voice and desktop-control features require separate setup.

### [Robotathon 2025](https://github.com/moneerhijaz/robotathon-2025)

ESP32 firmware for our first-place competition robot, combining Bluetooth control, line following, color sensing, and infrared wall navigation. The repository includes calibration notes, alternative control experiments, and KiCad design files. It records the engineering behind the robot, including its reproduction limits.
